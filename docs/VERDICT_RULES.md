## 2. v2 구조
**① 전략 점수(-5~+5)** — 다섯 요인(각 -1/0/+1), 수준이 아니라 변화·신선도로 판정
- F1 이익추정 리비전(최근 2주): 상향 우세 +1 / 혼재·없음 0 / 하향 우세 -1
- F2 업황 가격 전망 방향(최신 분기 TrendForce 등): 상승 +1 / 보합·혼재 0 / 하락 -1
- F3 밸류에이션 괴리: 목표가 평균 괴리가 +30% 초과면 +1, -10% 미만이면 -1, 그 사이 0. **단 목표가 중앙 보도일 이후 주가가 ±15% 넘게 움직였으면 낡은 목표가로 보고 0**(괴리율은 주가가 빠질수록 커지는 순환 구조라 그대로 쓰면 항상 긍정)
- F4 정책·규제·외부 이벤트 리스크: 미해소 중대 외부 리스크 -1 / 없음·해소 중 0 / 해소 확인 +1
- F5 수급(외국인 5거래일 누적): 대규모 순매도(-2조원 미만) -1 / 중립 0 / 순매수 지속 +1
- 라벨: 점수 ≥ +2 긍정, ≤ -2 부정, 그 외 중립. 라벨 변경은 점수 변화 2 이상 또는 같은 라벨 2회 연속 종가 확정일 때만(히스테리시스).

**② 위험 레짐(방향과 분리)** — 10일 실현변동성 vol10, 20일 고점 대비 낙폭 dd20
- 극단: vol10 ≥ 6% 또는 dd20 ≤ -25% / 높음: vol10 ≥ 4% 또는 dd20 ≤ -15% / 보통: 그 외
- 비중 배수 = clip(3% ÷ vol10, 0.2~1.0)(변동성 타깃팅, 예측이 필요 없음)

**③ 전술 플래그(참고)** — 과매수는 신규 매수 보류, 과매도는 방향 판단에 쓰지 않음

**④ 최종 라벨·확신도** — 전략 긍정→매수(위험 극단이면 소규모·분할), 중립→중립, 부정→매도. 확신도: 위험 극단이면 낮음, 그 외 |점수|≥3 높음 / =2 중간 / 그 외 낮음. 과매수 플래그가 켜지면 매수를 중립으로 낮춘다.

## 3. 한계
- 전략 요인(F1~F5)은 과거 시점별 값이 저장돼 있지 않아 **백테스트하지 못했다**. v2의 전략 요인 설계는 v1 실패 원인(항상 +1인 요인, 뉴스 후행, 낡은 목표가, 외부 리스크·수급 부재)에 대한 구조 개선이며 예측력 검증은 앞으로 이 판정 이력이 쌓여야 가능하다.
- 변동성 타깃팅으로 위험은 줄지만(같은 기간 3% 타깃 -38.2% vs 단순 보유 -48.1%) 하락 추세 구간이어서 어떤 비중 축소도 유리했다. 상승장·횡보장 검증은 아직 없다.
- 본 판정은 정보 제공용 분석이며 개인 투자 권유가 아니다.
